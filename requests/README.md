# Requests

A request file triggers the public GitHub Actions web fetcher.

Example:

```json
{
  "url": "https://example.com/article",
  "requested_by": "chatgpt"
}
```

## Important

This repository is public. Request files and their Git history are public.

Only submit URLs that are themselves safe to disclose publicly. Never place credentials, cookies, tokens, private URLs, customer systems, or internal documents here.
